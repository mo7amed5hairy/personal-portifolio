🔍 التوثيق الشامل لمعرض الأعمال الاحترافي

مرحباً بك! هذا الدليل يهدف لمساعدتك في تثبيت وتخصيص واستخدام مشروع "معرض الأعمال" المطور بتقنية Laravel 12. يرجى اتباع الخطوات بدقة لضمان عمل كافة المميزات.

2. المتطلبات والبيئة التشغيلية

  • PHP: الإصدار 8.2 أو أحدث (مفضل 8.3).
  • Composer: الإصدار 2.6 فما فوق.
  • Node.js: الإصدار 18 فما فوق (لإدارة الواجهات الأمامية).
  • قاعدة بيانات: MySQL (إصدار 8 فما فوق) أو SQLite.
  • خادم الويب: Apache أو Nginx (مع تفعيل mod_rewrite).

3. تثبيت المنتج (على السيرفر المحلي)

لتشغيل المنتج على جهازك الشخصي باستخدام برامج مثل Laragon أو XAMPP، اتبع الآتي:

  1. قم بفك ضغط ملفات المشروع في مجلد الخادم المخصص.
  2. افتح الطرفية (Terminal) داخل مجلد المشروع وقم بتنفيذ الأوامر التالية بالترتيب:
# تثبيت المكتبات البرمجية
composer install

# تثبيت مكتبات الواجهة الأمامية
npm install

# بناء ملفات التصميم
npm run build

4. التثبيت على الاستضافة (cPanel / VPS)

  1. قم برفع كافة الملفات إلى مجلد public_html (أو مجلد فرعي حسب رغبتك).
  2. تأكد من أن المجلد الرئيسي (Document Root) يشير إلى مجلد public داخل المشروع.
  3. أعط صلاحيات الكتابة (775) للمجلدات التالية:
    • storage
    • bootstrap/cache

5. إعداد قاعدة البيانات وملف البيئة

1. قم بإنشاء قاعدة بيانات جديدة عبر phpMyAdmin:

2. انسخ ملف .env.example وقم بتسميته إلى .env.

3. عدل إعدادات الربط في ملف .env لتطابق بيانات القاعدة التي أنشأتها:

4. نفذ الأوامر التالية لتهيئة الجداول وبذر البيانات الافتراضية:

php artisan key:generate
php artisan migrate --seed
php artisan storage:link

6. طريقة الاستخدام

بعد إتمام الخطوات السابقة، يمكنك تصفح الموقع عبر الرابط المحلي أو رابط الاستضافة. ستجد الموقع يعرض بيانات افتراضية يمكنك تعديلها بالكامل.

7. لوحة التحكم (Admin Dashboard)

لوحة التحكم تتيح لك إدارة كامل للمحتوى دون الحاجة للمساس بالكود البرمجي.

  • رابط الدخول: yoursite.com/admin/login
  • بيانات الدخول الافتراضية:
    • البريد: admin@example.com
    • كلمة المرور: password123 (أو التي حددتها في الـ Seeder).
نصيحة: يمكنك تغيير بيانات السيرة الذاتية والشعار من قسم "الملف الشخصي" داخل لوحة التحكم.

8. التعديل والتخصيص

أ- تغيير الألوان:

المشروع مبني باستخدام **Tailwind CSS 4**. لتغيير اللون الأساسي:

  1. افتح ملف tailwind.config.js.
  2. عدل قيم الألوان في قسم primary.
  3. نفذ npm run build لتطبيق التغييرات.

ب- تعديل النصوص (الترجمة):

يمكنك تعديل أي نص ثابت في الموقع عبر ملفات الترجمة في المسار:

  • resources/lang/ar/messages.php
  • resources/lang/en/messages.php

ج- إضافة مشاريع جديدة:

من لوحة التحكم، اذهب لقسم المشاريع، واختر "إضافة جديد". يمكنك رفع الصور وتحديد التقنيات المستخدمة وسيظهر المشروع تلقائياً في الصفحة الرئيسية.

9. استكشاف الأخطاء وإصلاحها

مشكلة: الخطأ 500 عند التشغيل على الاستضافة.
الحل: تأكد من أن إصدار PHP هو 8.2+، وتأكد من حذف الملفات داخل bootstrap/cache/ كما شرحنا سابقاً.
مشكلة: الصور لا تظهر بعد الرفع.
الحل: تأكد من تنفيذ الأمر php artisan storage:link.
