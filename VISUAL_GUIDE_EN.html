🔍 Comprehensive Graphic Installation & Operation Guide

This guide is designed to simplify the setup of the "Professional Portfolio" project.

1. Environment Setup & Terminal Commands

Start by opening your Terminal in the project root directory and run the following essential commands to install dependencies and generate application keys.

  • composer install - To install PHP dependencies.
  • php artisan key:generate - To secure the application.
  • npm install && npm run build - To build frontend assets (CSS/JS).

2. Database Creation (phpMyAdmin)

Go to localhost/phpmyadmin and create a new database to link with the website.

Preferred database name: portfolio_db with utf8mb4_unicode_ci collation.

3. Local Environment/Linkage (.env)

Modify your .env file to connect the source code with the database you created.

💡 Important Note:
After completion, run php artisan migrate --seed to create the tables and seed default data.

4. Final Website Preview (Full Stack Developer)

Your website is now ready to shine! Enjoy your new professional portfolio lived locally or on your server.

5. Admin Dashboard

You can manage all website content (projects, text, bio) through a professional and user-friendly admin dashboard.
