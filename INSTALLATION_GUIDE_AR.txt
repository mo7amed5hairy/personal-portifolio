####################################
🔧 1. المتطلبات الأساسية
####################################

### متطلبات السيرفر:
- PHP 8.2 أو أحدث (مفضل 8.3)
- Composer 2.6 أو أحدث
- MySQL 8.0 أو أحدث (أو SQLite)
- Laravel Framework 12.x
- Node.js 18 أو أحدث مع npm

### إضافات PHP المطلوبة:
- BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO, Tokenizer, XML, GD

####################################
💻 2. التركيب على السيرفر المحلي
####################################

### الخطوة 2.1: إعداد البيئة المحلية
- تثبيت Laragon (موصى به) أو XAMPP.
- تأكد من تفعيل PHP 8.2 وإصدار MySQL حديث.

### الخطوة 2.2: نسخ الملفات
- قم بفك ضغط ملفات المشروع في مجلد www (لـ Laragon) أو htdocs (لـ XAMPP).
- المسار المثال: C:\laragon\www\personal-portifolio

### الخطوة 2.3: فتح الطرفية (Terminal)
- افتح terminal داخل مجلد المشروع.

####################################
🗄️ 3. إعداد قاعدة البيانات
####################################

### الخطوة 3.1: إنشاء قاعدة البيانات
1. افتح phpMyAdmin.
2. أنشئ قاعدة بيانات جديدة باسم portfolio_db.
3. اختر الترميز utf8mb4_unicode_ci.

### الخطوة 3.2: تهيئة الجداول
- لا تحتاج لاستيراد ملف SQL يدوي، سنستخدم أوامر Laravel لاحقاً.

####################################
⚙️ 4. تكوين ملف البيئة (.env)
####################################

### الخطوة 4.1: إنشاء ملف .env
- انسخ ملف .env.example وقم بتسميته إلى .env.
- الأمر: cp .env.example .env

### الخطوة 4.2: تعديل الإعدادات
افتح ملف .env وعدل البيانات التالية لتناسب جهازك:

APP_NAME="محمد خيري - معرض الأعمال"
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=portfolio_db
DB_USERNAME=root
DB_PASSWORD=

####################################
📦 5. تثبيت الاعتمادات (Dependencies)
####################################

نفذ الأوامر التالية بالترتيب:

# تثبيت اعتمادات PHP
composer install

# توليد مفتاح التطبيق
php artisan key:generate

# تثبيت اعتمادات JavaScript
npm install

# بناء ملفات التصميم (CSS/JS)
npm run build

# تشغيل التهجير وبذر البيانات (Migrations & Seeders)
php artisan migrate --seed

####################################
🚀 6. تشغيل المنصة
####################################

### تشغيل السيرفر المدمج:
php artisan serve

- المنصة ستكون متاحة على: http://localhost:8000

####################################
🔐 7. حساب الإدارة (Dashboard)
####################################

بما أن النظام لا يحتوي على مستخدم افتراضي، يمكنك إنشاء حساب مدير عبر Tinker:
php artisan tinker

ثم اكتب:
User::create(['name' => 'Admin', 'email' => 'admin@example.com', 'password' => bcrypt('password123')]);

- رابط لوحة التحكم: http://localhost:8000/admin/login

####################################
🎨 8. دليل التعديلات والتخصيص
####################################

### 8.1 الصور والملفات
- يتم رفع الصور عبر لوحة التحكم وتخزن في storage/app/public.
- لربط المجلد بالببليك نفذ: php artisan storage:link.

### 8.2 تعديل الألوان (Tailwind CSS)
- افتح ملف tailwind.config.js لتعديل مصفوفة الألوان primary.
- افتح resources/css/app.css لتعديل المتغيرات الأساسية (CSS Variables).

### 8.3 تعديل اللغات
- النصوص موجودة في resources/lang/ar و resources/lang/en.

####################################
🔧 9. إعدادات السيرفر (للاستضافة)
####################################

### 9.1 ملف .htaccess
- تأكد من وجوده في مجلد public ليتم تحميل الموقع بشكل صحيح من الـ root.

### 9.2 صلاحيات المجلدات (Permissions)
chmod -R 775 storage
chmod -R 775 bootstrap/cache
