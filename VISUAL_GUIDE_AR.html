🔍 دليل التركيب والتشغيل الجرافيكي الشامل

هذا الدليل مصمم لتسهيل عملية تنصيب مشروع "معرض الأعمال الاحترافي" لمحمد خيري.

1. إعداد البيئة والطرفية (Terminal)

ابدأ بفتح الـ Terminal في المجلد الرئيسي للمشروع وقم بتنفيذ الأوامر الأساسية لتثبيت المكتبات وتوليد مفاتيح التطبيق.

  • composer install - لتثبيت مكتبات PHP.
  • php artisan key:generate - لتأمين التطبيق.
  • npm install && npm run build - لبناء ملفات الواجهة (CSS/JS).

2. إعداد قاعدة البيانات (phpMyAdmin)

توجه إلى localhost/phpmyadmin وأنشئ قاعدة بيانات جديدة لربطها بالموقع.

اسم قاعدة البيانات المفضل: portfolio_db مع ترميز utf8mb4_unicode_ci.

3. تكوين ملف الربط (.env)

قم بتعديل ملف .env لربط الأكواد بقاعدة البيانات التي أنشأتها.

💡 ملاحظة هامة:
بعد الانتهاء، نفذ الأمر php artisan migrate --seed لإنشاء الجداول وبذر البيانات الافتراضية.

4. المعاينة النهائية للموقع (مطور ويب متكامل)

الآن، الموقع جاهز للعمل! استمتع بمعرض أعمالك الجديد والاحترافي.

5. لوحة التحكم (Admin Dashboard)

يمكنك التحكم في كافة محتويات الموقع (المشاريع، النصوص، السير الذاتية) من خلال لوحة تحكم احترافية وسهلة الاستخدام.
